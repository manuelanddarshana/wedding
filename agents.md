# AGENTS.md

## Architecture

TanStack Start app (file-based routing via `@tanstack/react-router`). Two
routes only:

- `/` (`src/routes/index.tsx`) — hero + wedding schedule
- `/travel` (`src/routes/travel.tsx`) — post-wedding trip, accommodation,
  flights, visa, weather, RSVP

`src/routes/__root.tsx` sets up the HTML shell and page metadata.
`src/router.tsx` wires the generated route tree (`src/routeTree.gen.ts`,
auto-generated by the TanStack router Vite plugin — do not hand-edit it).

Content lives in `src/data/wedding.ts` (schedule items, venues, RSVP form
URL, e-Visa URL) rather than being hardcoded in the route components, so
dates or links can be updated in one place.

## Styling

Tailwind CSS v4 (`@tailwindcss/vite`, imported via `src/styles.css`).
Design tokens (the "strawberry matcha" palette — pinks and light greens) are
plain CSS custom properties defined in `src/styles.css` (`--strawberry-*`,
`--matcha-*`, `--cream`, `--ink`) and referenced from Tailwind utility
classes as arbitrary values, e.g. `text-[var(--strawberry-deep)]`. Keep new
colors consistent with these tokens rather than introducing new hex values
inline.

Fonts: Fraunces (display/headings) and Karla (body), loaded via Google
Fonts `@import` in `src/styles.css`.

Decorative line-art (leaf sprig, berry cluster) lives in
`src/components/Motifs.tsx` as inline SVG — no external image assets.

## Conventions

- No CMS/database — this is a static informational site, content changes
  are code changes to `src/data/wedding.ts`.
- Keep copy brief; this site intentionally avoids marketing-style filler
  text per the original request.
- External links (RSVP Google Form, Indian e-Visa portal) open in a new
  tab (`target="_blank" rel="noreferrer"`).
